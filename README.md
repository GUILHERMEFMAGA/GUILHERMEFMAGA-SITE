# Super Agente Local

Agente de automacao que roda **sozinho, sem internet, sem API paga e sem Ollama**.
So Python da Microsoft (biblioteca padrao) + Git + Windows.
Criado do zero no VS Code para aprender, na pratica, o que faz um agente auto-melhoravel.

> A tese do projeto: "erro zero" nao existe. O que existe e **erro que nao cola**:
> detectar, medir, reverter, aprender.
