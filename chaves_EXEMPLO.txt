# ============================================================
#  ARQUIVO DE CHAVES DO SUPER AGENTE
#  Como usar (o jeito MAIS FACIL):
#    1) Dê 2 cliques em  CONFIGURAR_CHAVES.bat
#       (ele cria este arquivo como  chaves.txt  e abre no Bloco de Notas)
#    2) Cole cada chave depois do sinal de igual (=), SEM aspas.
#    3) Salve (Ctrl+S), feche o Bloco de Notas e o agente ja abre.
#
#  VOCE NAO PRECISA PREENCHER TUDO!
#  - As linhas que comecam com # estao desligadas.
#  - Se deixar uma chave como "cole_aqui" (de exemplo), o agente a ignora.
#  - MESMO SEM NENHUMA CHAVE, o agente funciona (ele tem IAs gratuitas
#    que nao pedem cadastro: LLM7 e Pollinations).
#  - Quanto mais chaves voce colocar, mais "folego" diario o agente tem.
#
#  Todas as chaves abaixo sao GRATUITAS e NAO pedem cartao de credito.
#  Este arquivo fica so no seu PC (esta no .gitignore) e NUNCA vai pro GitHub.
# ============================================================
